📌 Sobre este repositório

Este repositório é a nova versão oficial do projeto PetMatch.

O projeto foi transferido para uma nova conta do GitHub devido a um incidente de segurança envolvendo o acesso à minha conta anterior, que foi comprometida por terceiros.

Por esse motivo, precisei criar um novo repositório para continuar o desenvolvimento e manter o projeto disponível.

O desenvolvimento do PetMatch continua normalmente. A migração foi realizada para garantir a continuidade do projeto e centralizar futuras atualizações nesta nova conta.

Observação: o histórico de desenvolvimento e os arquivos do projeto foram preservados durante a migração.
